# SK Hynix: Kundenkonzentration und Vertriebsregionen laut Filing

## Aussage
- Größter Kunde 2025: 23,9 % des Umsatzes.
- Q1 2026: die zwei größten Kunden 14,8 % und 12,4 %.
- Umsatz über US-Vertriebsgesellschaften: 64,7 % (Q1 2026), 68,8 % (2025). Über China-Vertriebsgesellschaften: 24,3 % (Q1 2026), 19,7 % (2025).
- Umsatzmix DRAM / NAND: 77,3 / 22,0 % (Q1 2026), 77,1 / 21,3 % (2025), 67,6 / 29,1 % (2024), 63,4 / 29,5 % (2023).

## Trägt
Die Größenordnung der Abhängigkeit vom größten Kunden. Vorbedingung für das Werkzeug "Verhandlung über Außenoptionen" (Rentenaufteilung hängt an der Kundenkonzentration).

## Trägt nicht
Wer die Kunden sind; das Filing nennt keine Namen. Auch nicht, ob der Rückgang von 23,9 % auf 14,8 % Diversifizierung ist oder eine Umschichtung zwischen zwei Großkunden, und nicht, ob dieselbe Firma über mehrere Vertriebswege bestellt. Vertriebsregion ist Sitz der Vertriebsgesellschaft, nicht Ort des Endverbrauchs.

## Bruchindikator
Ein Kunde über 30 % in einem Geschäftsjahr, oder die zwei größten zusammen über 40 %.
