Aussage

Die uebernommene PVS-Pipeline (MATLAB, Edinburgh; FreeSurfer, FSL, RORPO) liest die Fallkennungen mit readtable aus einer CSV. Kennungen wie 1, 10, 100 werden dabei numerisch, und MATLAB macht aus [StudyTag '_T1w_reoriented'] das Zeichen char(Fallnummer) als Praefix jedes Dateinamens (65 -> A, 100 -> d, 50 -> 2, 58 -> :, 10 -> Zeilenumbruch). Faelle, deren Code ein Shell-Sonder- oder Steuerzeichen ergibt, brechen in fslreorient2std/run_samseg ab (26 von 30); vier weitere (Codes ., 0, 2, C) brechen spaeter und sind getrennt anzusehen. Die gemeldeten Fehlertexte ("Error changing the orientation", "Unrecognized file type _template_LBG") und die leere Spalte "Study Tag" in der Fehlerliste (fprintf('%s', Zahl)) sind Folgefehler derselben Ursache. Ergebnis: 73 Faelle mit Masken statt 72 gemeldet; mit Textkennungen (z. B. sub-001) laufen alle.

Traegt

Jede uebernommene Pipeline mit Kennungen aus CSV; jede Sprache, die Zahl und Zeichen implizit wandelt. Vor dem Deuten von Fehlertexten: erstes Byte der erzeugten Dateinamen ansehen (od -c).

Traegt nicht

Sagt nichts ueber die Qualitaet der Masken. Die vier Restfaelle sind nicht erklaert.

Bruchindikator

Ein Lauf mit Textkennungen auf den 30 Faellen scheitert erneut.

Ablesung

Eigene Zaehlung (pvs-arena/skripte/bestandsaufnahme.py, daten/BESTANDSAUFNAHME.md), Code PVS_lib/Utils/process_dataset_from_csv_files.m Zeile 7 und 14. Patientendaten, nur Summen.
