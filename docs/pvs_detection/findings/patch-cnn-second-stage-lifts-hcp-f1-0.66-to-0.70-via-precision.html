Aussage

Gleiches Protokoll wie auf VALDO (5-fach nach Fall, je Startwert 2 Schwellenfaelle zurueckgehalten, 3 Startwerte, 25 Epochen), aber 200 Faelle einer Geometrie (0,8 mm), nur T2, DRIPS-Kandidaten (Posterior >= 0,1), 143.461 Kandidaten: CNN allein 0,693 [0,680; 0,705], GBM 0,660 [0,648; 0,672], Mischung 0,695 [0,682; 0,707]. Gepaart Mischung - GBM +0,035 [+0,032; +0,038], besser in 191/200. Der Gewinn ist Praezision (gepoolt 0,821 -> 0,899, Fehlalarme 14.366 -> 7.480) bei gleichem Recall (0,563 -> 0,572); Klasse 1-2 bleibt bei Recall 0,24 -- die kleinen PVS fehlen schon im Kandidatensatz, nicht erst im Trenner. Gegen den alten Trenner F3 (0,668, in-sample-Schwelle) +0,026, besser in 163/200.

Traegt

Der Bruchindikator des VALDO-Befunds ist eingetreten: der CMB-Hebel (gemeinsames kleines 3D-CNN auf Kandidaten) traegt auch bei PVS, sobald genug Positive einer Geometrie vorliegen (~80k statt ~1k). Fuer die HCP-Entwicklungslinie ist Mischung CNN+GBM der neue Stand. Rezept: Patch 16 mm um den Schwerpunkt, Kanaele T2z/Komponentenmaske/Posterior, Flips + Verschiebung, BCE mit pos_weight, AdamW.

Traegt nicht

Expertenevidenz: 160/200 HCP-Masken sind U-Net-Silber (nur WM). Ob der Gewinn auf Handreferenzen uebertraegt, zeigt erst der Uebertrag HCP -> VALDO-T2 (Versuch G3). Recall-Gewinn fuer kleine PVS: keiner; dafuer muss der Kandidatengeber (DRIPS-Schwelle) empfindlicher werden, dann kann das CNN mehr aussortieren (Versuch G4).

Bruchindikator

Auf VALDO-T2-Kandidaten (12 Handfaelle) liegt das HCP-trainierte CNN+GBM nicht ueber dem VALDO-eigenen GBM auf denselben Kandidaten.
