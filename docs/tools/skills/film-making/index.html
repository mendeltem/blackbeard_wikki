film-making: Agent Skill for narrated animated films

tools/skills/film-making · SKILL · GitHub

Purpose

Holds the order of work and the house rules for a film made with manim_film, so that they are not typed again and not collected from many notes: source sheet first, script with roles, voice, chapters, quick render and gate, contact sheets, full render, vision check for public films, deliver folder. The craft itself (what makes a picture good, engine calls) stays in the tool folder; the skill points to it.

When to use, when not

Use for every film, animation, tutorial or lecture video with a voice, also for a re-render or one failed gate line. Not for a single static figure, a slide deck or a screen recording.

The rules it carries

  • An explanation film is always animated, drawn in Python with the film tool (user 2026-11-24). Never a slide show of stills. Real images may sit inside a chapter, the explaining is done by motion.
  • Length follows complexity, not minutes (user 2026-11-24): simple = short and to the point; normal = as long as it takes so that everything is explained; complex = long and detailed. The chapter counts in the table of SKILL.md (1 to 2, 3 to 6, 7 or more) are an orientation added by the author of the skill, not a user rule.
  • Source first; no prediction questions and no countdowns; pronunciation is asked, not guessed; films with patient data never leave the internal drive and get no vision check; look at every contact sheet yourself; CPU only, at most 4 render processes; English.

Install

cp -r tools/skills/film-making ~/.agents/skills/film-making
ln -s ~/.agents/skills/film-making ~/.claude/skills/film-making     # Claude Code

Needs the wiki checkout (the skill expects the tool at ~/blackbeard_wikki/tools/general/manim_film) and the two conda environments of the tool (see tools/general/manim_film/INSTALL.md).

Files

SKILL.md (80 lines), scripts/new_film.sh (empty film folder with source sheet, beats, chapters), scripts/film_page.py (deliver folder: film, index.html with chapter buttons and a linked source list, parts/), references/deliver.md (deliver folder, video-platform package, storage), evals/evals.json (3 cases).

Limits

Tested with Claude Code only. Bound to this film tool and its environments. The vision check of the first film did not run, because the film folder lay under the data directory that the checker refuses on purpose; the skill now tells to start public films outside it.
