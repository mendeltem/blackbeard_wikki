Kette insgesamt: 0,245 -> 0,647. Zweite Stufe als EIN Modell: ein 3D-CNN auf dem Kandidaten-Pool aller Kohorten (eine Schwelle 0,30, out-of-fold je Fall) ist auf VALDO und T2* gleich der Liquor-Regel und auf SWI +0,061 besser; es braucht keine Gewebekarte.

Der Engpass ist die Trennung Blutung / Gefaessquerschnitt mit einer einzigen Magnitudensequenz.

Getragen (Verlaeufe): Der Trainingsverlust ordnet weder Netze noch Trainingslaengen: gleicher Verlust bei F1 0,176 gegen 0,404; 90/120 Epochen senken den Verlust, nicht den Out-of-fold-Wert; Fruehstopp auf dem inneren F1 feuert auf Startwert-Rauschen, darum feste 60 Epochen.

Regel (5)

RegelExample scripts that restate a pipeline must reproduce its command bit for bitvorschlag2026-10-22Example scripts (train, predict, fine-tune) against the commands on the CPU with fixed seeds: weights equal with torch.equal, masks voxel for voxel; one comparison with a model that finds lesions; copies checked by source text (2026-10-22)

Herkunft: Python examples of cmb_3d_unet_experiments (branch python-examples, commit 53b21a0), own runs 2026-10-22 · eigene Seite · Markdown

Aussage

Readable example scripts (train, predict, fine-tune written out step by step) are only trustworthy if a test shows that they compute what the package's own commands compute. With fixed seeds on the CPU that is an exact test, not a tolerance:

  1. Weights equal with torch.equal, masks equal voxel for voxel. Measured 2026-10-22: 01_train_unet.py against cmbx train --frst_from cmbx, 03_fine_tune_unet.py against cmbx fine_tune --frst_from cmbx (same weights, same held-out cases, same threshold and minimum size), 02_predict_microbleeds.py against cmbx evaluate (same masks on the scan grid, same lesion counts).
  2. Equality needs the same order of random draws: seed torch, then the numpy generator, then build the network, then the optimizer over the same parameter list, then the patch draws in the same order. Predicting the held-out cases draws nothing, so the script may evaluate at other epochs without changing the weights.
  3. Two empty masks prove nothing. Keep one comparison with a model that finds lesions: the public VALDO model found 88 and 69 voxels on the two synthetic phantoms, and the test asserts a count above zero.
  4. Copies stay copies: scripts meant to be read alone repeat a few functions; a test compares their source text (inspect.getsource), so a fix in one cannot silently miss the other.
  5. Numbered top-level scripts with a process pool need the if __name__ == "__main__": guard around the steps (spawn and forkserver re-import the main module); functions stay above it, tests load the file with importlib.

Trägt

13 tests (about 90 s on 4 CPU threads, tiny network of width 8), full suite 322 green in a fresh environment. The same scripts gave the same numbers on a second run in a new environment (held-out F1 0.133 and 0.100 at epoch 1 and 2, identical to the command).

Trägt nicht

Bit equality holds for one machine and one PyTorch build on the CPU; on a GPU (bfloat16 autocast) and across releases only closeness can be expected (PyTorch documentation). The from-zero check ran on the development workstation: a new local environment, and a delegated "remote" agent that in fact ran on the same machine (GPU hidden, warm pip cache). A truly fresh CPU-only machine is still open; such a check must first record host name and GPU, otherwise it does not count as a fresh machine.

Bruchindikator

A seed-for-seed rerun of script and command on the CPU that gives different weights, or a predict comparison whose masks are all empty.

Ablesung

PyTorch, "Reproducibility" notes (https://docs.pytorch.org/docs/2.14/notes/randomness.html, checked 2026-10-22): completely reproducible results are not guaranteed across releases, commits or platforms, nor between CPU and GPU; torch.manual_seed seeds the generator for all devices, and with other nondeterminism removed the same environment gives the same numbers. Python, multiprocessing, "Safe importing of main module" (https://docs.python.org/3/library/multiprocessing.html, checked 2026-10-22): with spawn or forkserver the main module must import without side effects; protect the entry point with if __name__ == '__main__':; since Python 3.14 forkserver is the POSIX default. Code: https://github.com/mendeltem/cmb_3d_unet_experiments (examples/python, tests/test_python_examples.py). Own runs 2026-10-22 on synthetic phantoms only.

Aussage

A detector that works on a fine grid (0.5 x 0.5 x 1 mm) and writes its mask back onto the scan grid (e.g. 0.7 x 0.7 x 5 mm slices) can merge two neighbouring microbleeds into one connected component of the binary mask: measured 37 separate detections on the model grid, 36 components after resampling (nearest neighbour in world coordinates). Microbleeds smaller than one input voxel can also vanish (kept here by setting their centre voxel). Rule: the count comes from the model grid; besides the binary mask, write a label map in which detection k has value k and matches entry k of the report (volume, probability, centre in mm and as input voxel).

Trägt

Acceptance test on real scans: json count = distinct values of the label map = model-grid count for every case after the change; before it, three of three checks on 5 mm data failed.

Trägt nicht

Says nothing about whether the merged pair is clinically one or two microbleeds; the model grid decides.

Bruchindikator

Counting components of a binary mask on thick slices and comparing them with a report.

Ablesung

Aussage

Ein Fall ohne Referenzlaesion hat kein F1: mit einem Fehlalarm ist es 0, ohne Fehlalarm undefiniert. Wer Gesunde in ein "F1 je Fall, Mittel" mischt, zieht die Zahl nach unten und sagt nichts ueber die Erkennung. Deshalb: 1. Zwei Gruppen in jeder Zusammenfassung und Fallliste: Faelle mit Referenzlaesionen (F1 je Fall, Mittel; gepooltes F1; FP je Fall) und Gesunde (FP je Fall; Anteil mit >= 1 Fehlalarm; Fall-Spezifitaet = Anteil ohne Fehlalarm). 2. Das gepoolte F1 ueber alle Faelle darf zusaetzlich stehen (die Fehlalarme der Gesunden sind echte Fehlalarme), aber mit Angabe, dass es beide Gruppen enthaelt. 3. In der Fallliste bekommen Gesunde eine eigene Ueberschrift und zeigen nur "FP n" oder "clean"; die Kopfzeile sagt "healthy control", nicht "F1 0.00". 4. Fuer Berichte und Paper: F1-Mittel je Fall nur ueber Laesionsfaelle; Gesunde als Spezifitaetszahl daneben.

Umgesetzt im Generator cmb/review/build_slice_viewer.py (summary(), buildList(), Kopfzeile), 12.10.2026; alle vier Stick-Seiten per --refresh-html neu gebaut. Beispielhafte Wirkung (eigene Kohorten, nur Richtung): das Fallmittel stieg von 0,37 bzw. 0,47 (mit Gesunden) auf 0,63 bzw. 0,64 (nur Laesionsfaelle); das gepoolte F1 aenderte sich kaum.

Mittel gegen gepoolt (Nutzerfrage 12.10.): F1 mean = F1 je Fall, dann Mittel ueber die Faelle -- jeder Fall zaehlt gleich, ein Fall mit 2 Blutungen so viel wie einer mit 100; empfindlich fuer kleine Faelle. Pooled = TP, FP, FN ueber alle Faelle summiert, daraus ein F1 -- jede Blutung zaehlt gleich, grosse Faelle dominieren. Liegt pooled ueber mean, laufen die kleinen Faelle schlechter. Beide nennen, nie eins fuer das andere ausgeben.

Jede Laesionsdetektion mit Kontrollfaellen (CMB, PVS, WMH-Null-Faelle); jede QC-Seite und jede Tabelle mit "F1 je Fall".

Traegt nicht

Datensaetze ohne Kontrollfaelle (VALDO Task 2 hat in jedem Fall Blutungen); voxelweise Dice-Masse.

Befund (17)

BefundCMB detection 2023-2026: SHIVA-CMB is the public comparable, mimics drive precision, foundation models are not CMB-readyvorschlag2026-10-17Review 2023-2026 (37 records): SHIVA-CMB (public 3D U-Net, 6 cohorts, T2*+SWI, F1 0.74, 0.6 FP/scan, weights released) is the comparable to run; precision not sensitivity separates methods; mimic handling via phase/QSM channels; no CMB-specific foundation model retrieved

Herkunft: Literature review d_cmb_detection (PubMed E-utilities + Europe PMC, 37 retrieved records), report /home/uchralt/cle-arbeit/recherche/d_cmb_detection/REPORT.md, 2026-10-17 · eigene Seite · Markdown

Aussage

A literature review of automatic CMB detection on SWI/T2* (PubMed + Europe PMC, 37 retrieved records; arXiv not reachable, HTTP 429 through the proxy) gives three actionable results for this project:

  1. The closest published analogue of our chain is SHIVA-CMB. One 3D U-Net trained once on 450 scans from 7 acquisitions and 6 cohorts, T2 and SWI mixed (Tsuchida 2024, PMID 39730628): held-out test sensitivity 0.67, precision 0.82, F1 (Dice) 0.74, 0.6 false positives per scan; on an evaluation-only set with acquisitions never seen in training 0.67 / 0.91 / 0.77 / 0.5 FP; correlation with expert visual counts in 1,992 T2-weighted scans Pearson R 0.89. Both the pipeline (SHiVAi) and the pretrained weights (SHIVA-CMB) are public -- a free external baseline we should run on our data.
  2. Precision, not sensitivity, separates the methods. The best lesion-level numbers reported 2023-2026 come from pipelines whose candidate stage is deliberately constrained: morphology filter bank + CNN, 95.0 % sensitivity at 4.37 FP/patient versus 97.5 % at 25.87 FP without the filter bank (Nishioka 2025, PMID 38494702); a geometric-to-neural cascade (GMM candidate generation + two 3D ResNets on QA labels) removing 76.8 % of stage-A false positives, F1 0.693, AUC 0.9587 (Bogdanov 2026 preprint, DOI 10.64898/2026.07.24.740624); U-Net with CBAM attention, large kernels and anatomy localisation, F1 0.887 at 0.83 FP/scan on 506 multi-site scans (Cho 2026, PMID 41859233). This matches our own negative finding that sensitivity levers do not raise lesion F1.
  3. Mimic handling is a contrast problem, not an architecture problem. Anatomical masking (ventricles/CSF/choroid plexus/cerebellum/edges) is a free false-positive filter present in the top pipelines -- consistent with our CSF rule.

Secondary results: synthetic CMBs are now a first-class training strategy (analytic model, 37,000 lesions released, ~9 FP/scan when trained on synthetic only, Momeni 2021, PMID 34051412; 3D lesion GAN transferring to unseen MRI parameters, PMID 34975381; self-supervised pseudo-labels giving +46 % average precision on ex-vivo T2, Nikseresht 2026, PMID 42107619). The SWI/T2 domain gap is measurable: synthesising SWI from T2 magnitude recovers 19/28 CMBs seen on real SWI versus 10/28 on magnitude images (Genc 2023, PMID 36733222). Meta-analytic pooled DL accuracy is high (lesion-level sensitivity 0.96 / specificity 0.98, patient-level 0.89 / 0.86, Feng 2026, PMID 42767630), but the authors themselves warn the study count is small. Aussage

  • MicrobleedNet (knowledge distillation, 3-step) reported cluster-wise TPR >90% with <2 false positives per subject and TPR >80% across datasets [1]; VALDO 2021 found 9 microbleed teams but large inter-team and inter-case variability and no practically useful result for lacunes [2]. These two anchors still define the field's reference numbers.
  • The dominant 2023–2026 architecture is unchanged in spirit: a 3D U-Net or 3D CNN detector, often with a second stage (classifier / refinement) for false-positive reduction [3,4,5,6,7,8]. What is new is the detail: attention-gated skip connections, region-proposal heads, hard-sample/prototype learning, triplanar ensembling, morphology filter banks, and geometric cascade candidate generation.
  • Lesion-level scores have crept up: e.g. precision 0.891 / recall 0.887 / F1 0.887 with 0.83 FP/scan on 506 multi-site scans [3]; a geometric-to-neural cascade reached F1 0.693 while removing 76.8% of stage-A false positives [8]; sensitivity ~96% at low FP for a single-stage triplanar ensemble [4] (unverified); ~95% at 4.37 FP/patient for a morphology-filter-bank + CNN on 2D T2* [6].
  • The most directly comparable public tool to our setup is SHIVA-CMB: one 3D U-Net trained once on 450 scans from 7 acquisitions / 6 cohorts (T2 and SWI mixed), test sensitivity 0.67, precision 0.82, F1(Dice) 0.74*, 0.6 FP/scan; on an unseen-acquisition set 0.67 / 0.91 / 0.77 / 0.5 FP — and it is publicly released (pipeline + weights) [9].
  • Domain shift SWI ↔ T2 is now addressed explicitly rather than ignored: cross-modality generalisation is reported as a headline result [3], synthetic-SWI-from-T2 synthesis recovers CMBs that are invisible on magnitude images (19/28 vs 10/28) [10], and zero-shot super-resolution of thick-slice SWI improves downstream CMB segmentation [11].
  • Synthetic data has become a first-class strategy: an analytic synthetic-CMB model with 37,000 generated lesions trains a detector to near state of the art (~9 FP/scan) using synthetic data only [12]; a 3D lesion GAN conditioned on volume/location transfers to unseen datasets with different MRI parameters [13]; self-supervised pretraining on ex-vivo T2* with fuzzy-segmentation pseudo-labels reached 90% of definite CMBs at 15 FP/scan [14].
  • Mimics remain the central problem and are handled mainly with extra contrast (high-pass filtered phase, QSM) and anatomical constraints rather than with new network families: QSM separates CMB from calcification better than SWI/phase [15]; a two-channel SWI + phase model reached sensitivity 95.8%, precision 70.9%, 1.6 FP/case [16]; QSM improved CMB-vs-iron separation (sensitivity 0.84–0.88, precision 0.40–0.59) [17].
  • Transformers and foundation models exist but are not yet CMB-specific in the retrieved literature: the retrieved foundation-model work is a universal brain-MRI lesion-segmentation model with a Mixture-of-Modality- Experts design evaluated on 8 lesion types (not CMB) [18], plus reviews of vision-language foundation models [19] and diffusion models [20] that list open problems (prompt dependence, mask hallucination, slow volumetric inference, limited annotation, domain-shift sensitivity) but report no CMB detection results.
  • External/cross-cohort validation is better than in 2021 but still the exception: SHIVA-CMB validates on unseen acquisitions and correlates with expert counts in 1,992 scans (R=0.89) [9]; nnU-Net was validated on independent internal and external sets [21]; other papers validate within one or two cohorts only [3,4,5].
  • Pooled meta-analytic DL accuracy looks high (lesion level sensitivity 0.96 / specificity 0.98; patient level 0.89 / 0.86) but the authors themselves flag the small number of studies and call for multicentre work [22]; SWI detects ~1.6× more CMBs than T2*-GRE, so sequence choice dominates any model comparison [23].

Practical recommendation (as written for our setup)

Setup: 3D U-Net per dataset plus an optional second-stage classifier; pooled lesion F1 (own number kept outside the wiki) on in-house T2*/SWI. The retrieved evidence maps onto this as follows.

  1. Our pooled F1 is in the expected band, but the comparison that matters is not published. SHIVA-CMB — one 3D U-Net across seven acquisitions and two modalities, i.e. the closest published analogue of "train once, apply to our data" — reports F1/Dice 0.74 (0.77 on unseen acquisitions) [9]. A per-dataset U-Net pooling below that is plausible but sits at the lower edge; the gap is most likely in false positives (mimics) rather than in sensitivity [3,6,8,16]. Report precision, recall and FP per scan separately, never F1 alone, because F1 hides exactly the trade-off that differs between datasets.
  2. Keep the two-stage design; invest in stage two. The retrieved false-positive wins come from the second stage: a 3D CNN discriminator on top of a 3D U-Net [7], a geometric cascade's second ResNet removing 76.8% of stage-A FPs [8], a morphology filter bank cutting 25.87→4.37 FP/patient [6], and knowledge distillation lifting cluster-wise TPR by 15% [1]. For our pipeline, an explicit stage-2 classifier trained on hard negatives (vessel cross-sections, calcification, iron, choroid plexus, image edges) is the single highest-value change — exactly the "optional second-stage classifier" we already have, but it should be trained deliberately on mimics.
  3. Add phase and/or QSM channels where available. The retrieved mimic literature is unambiguous: QSM separates CMB from calcification better than SWI/phase [15], and multi-modal T2w/SWI/QSM input improves CMB-vs-iron separation [17]. Adding a high-pass filtered phase channel is the cheapest step (sensitivity 95.8%, precision 70.9%, 1.6 FP/case reported with SWI+phase [16]). This attacks precision, our likely weak point.
  4. Use anatomical masking. Masking ventricles/CSF/choroid plexus/cerebellum/edges is cheap and was part of the top-performing pipelines [1,4,8]. It costs nothing at inference and requires no labels.
  5. Attack the T2*/SWI domain gap explicitly, since we train per dataset. Options in increasing effort: (a) train one model on both modalities and evaluate cross-modality as a first-class metric, as RLK-UNet [3] and SHIVA-CMB [9] do; (b) synthesise SWI from T2 magnitude with a DeepSWI-style network to normalise contrast [10]; (c) zero-shot super-resolution for thick-slice SWI before detection [11,30]. If per-dataset training is kept, at minimum report cross-dataset (SWI-model on T2 and vice versa) numbers so the domain gap is quantified.
  6. Use synthetic CMBs for augmentation and pre-training. The analytic 37,000-lesion synthetic set is released and reached ~9 FP/scan when training on synthetic only [12]; a 3D lesion GAN transfers to unseen datasets and different MRI parameters [13]; self-supervised pretraining with pseudo-labels lifted average precision by 46% over a real-data-only baseline in a low-prevalence, mimic-rich setting [14]. The GAN/synthetic route is particularly attractive for our per-dataset setup, where each dataset has few labelled lesions.
  7. Benchmark against SHIVA-CMB before building anything new. It is a public 3D U-Net trained across T2*/SWI cohorts with released weights [9]. Running it on our data gives a free, published external baseline and immediately shows whether our per-dataset F1 is a data problem or a pipeline problem.
  8. Do not expect transformers/foundation models to help yet. The retrieved foundation-model work targets generic brain lesion segmentation, not CMB [18], and the reviews list open problems (prompt dependence, mask hallucination, slow volumetric inference, domain-shift sensitivity, limited annotation) without CMB numbers [19,20]. Transformers are a research direction here, not a practical upgrade.
  9. Reporting discipline. Given VALDO's "performance inconsistency across cases" [2] and the meta-analysis's call for multicentre validation [22], report at minimum: lesion-level precision/recall/F1, FP per scan, cluster- wise detection at a fixed FP budget, and a subject-level count correlation — the last one is what SHIVA-CMB used to validate against expert reads in 1,992 scans (R=0.89) [9], and it is what clinical users actually need.

Trägt nicht

Abstract-level evidence only (no full texts read); a literature map, not a systematic review. Open questions:

  • No CMB-specific transformer or foundation model was retrieved. Whether vision-language or MoME-style foundation models transfer to 3–10 mm sparse lesions like CMBs is unverified [18,19].
  • Standardisation of metrics. "Cluster-wise TPR", Dice, lesion-level F1 and per-patient sensitivity are used interchangeably across the retrieved literature; no retrieved work provides a head-to-head comparison of the same models on the same data under one metric [1,3,9,22].
  • How much of the SWI-vs-T2* gap is contrast vs resolution? Super-resolution [11,30] and synthesis [10] both help, but no retrieved study decomposes the two effects.
  • Synthetic-data fidelity. Both the analytic model [12] and the GAN [13] claim transfer to unseen datasets, but neither reports an external lesion-level precision on a fully unseen modality (the GAN reports unseen MRI parameters, not unseen modality).
  • Post-2021 VALDO follow-up. No retrieved work is a successor benchmark to VALDO; the challenge's weak-label and case-level-inconsistency findings [2] have not been resolved by a new consensus evaluation.
  • ARIA-H / anti-amyloid context. RLK-UNet targets ARIA-H severity categories [3] and accelerated SWI is being evaluated for ARIA monitoring [36]; whether current detectors meet the regulatory bar for therapy monitoring is unaddressed.
  • arXiv gap in this report. Foundation-model and transformer preprints were not retrievable (proxy returned HTTP 429 / Rate exceeded. throughout); the foundation-model picture here is therefore limited to the peer-reviewed work that was retrieved [18,19,20].

Aussage

<sub>_space-T2S_desc-masked_T1.nii.gz von VALDO 2021 Task 2 enthaelt bei 33 von 72 Faellen NaN: sub-101 bis 106 rund 23 % der Voxel, sub-301 bis 327 (alle 27) 34-38 %. _T2S und _CMB sind bei allen Faellen sauber; in Kohorte 3 traegt zusaetzlich _T2 NaN. Es sind die GELIEFERTEN Dateien.

Teuer ist der lautlose Ausfall: NaN vergiftet die Perzentilnormierung von mri_synthseg, das Netz gibt ueberall Hintergrund aus, Rueckgabewert 0, Ausgabedatei vorhanden. Erst die nachgelagerte Rasterumrechnung faellt auf ("nur 1 Label"), und der Fall wird verworfen; die Rasterumrechnung stand zwei Stunden zu Unrecht unter Verdacht. Kein Gegenbeispiel in beide Richtungen: jeder NaN-Fall scheitert, jeder saubere liefert 33 Labels in 20-22 s.

Die Reparatur ist eine Zeile im Ladeschritt und geprueft sicher: np.nan_to_num(..., nan=0.0). Die NaN bilden eine Randschale vom Umrastern ausserhalb des Quellbilds (eine zusammenhaengende Komponente am Volumenrand, nach dreifacher Erosion der Hirnmaske kein NaN im Inneren); Nullsetzen erfindet keine Anatomie. An echten Daten bestaetigt: sub-304 von 1 Label / 0 Voxel auf 33 Labels / 1,65 M Voxel. Gelieferte Dateien nicht aendern.

Zwei Fallen beim Nachbauen: der Segmentierer leitet den AUSGABEnamen aus dem EINGABEnamen ab -- eine bereinigte Kopie erzeugt eine zweite Ausgabe neben der alten leeren, und ein Muster ohne sorted erwischt die alte. Und er ueberspringt vorhandene Ausgaben nur bei GLEICHEM Namen.
