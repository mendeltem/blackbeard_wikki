Aussage

MicrobleedNet (Sundaresan et al. 2023) discriminates candidates with a teacher-student network: a multi-task teacher (feature extractor, voxel-wise segmentor, patch classifier) and a student distilled from it (loss CE + 0.4 T^2 KL + 0.6 CE, T = 4 in the code). In the published code no command trains the teacher: train, fine_tune and cross_validate all build CDiscNet + CDiscClass24 and LOAD their weights from the model folder (cdisc_train_function.py, cdisc_finetune_function.py, crossvalidate_function.py). When the files are missing the inner handler only creates ValueError(...) without raise, so training continues and the student learns from a randomly initialised teacher. "Training MicrobleedNet from scratch" with this code therefore means step 1 from scratch and step 2 distilled from noise, unless the pretrained teacher files are put into the output folder.

Trägt

Read at the source (commit 958f1cb, verified as current main with git ls-remote). Consistent with the earlier observation that the fine-tuned original's student stayed at chance accuracy (0.5) on VALDO and two in-house cohorts while step 1 learned normally.

Trägt nicht

The original authors may train the teacher with code that was not published; the paper (Front Neuroinform 2023) describes teacher training. A from-scratch run of the original was not measured.

Bruchindikator

A later commit that trains CDiscNet (an optimizer over the teacher's parameters) or raises on a missing teacher.
