Aussage

Before a report, answer or wiki entry cites a source: (1) the source exists and its link works (PMID found in PubMed, DOI registered at doi.org), (2) the PMID belongs to the cited title, (3) the claim it backs is in its abstract, and (4) each reference carries one sentence "Shows: ..." with what the paper found. Anything that cannot be checked is marked "unverified". Never cite from memory; copy titles and ids from the retrieved record.

Trägt

2026-10-17: three research reports by the same agent and model (hospital model hub). Two were fully correct (22/22 and 39/39 references). The third had 20 of 28 references with REAL PMIDs attached to invented, generic titles ("Effect of infarcts and enlarged ventricles on automated subcortical segmentation" pointing at a paper on cortical thickness harmonisation). Real numbers made the wrong list look trustworthy; only the automatic comparison with PubMed found it.

Trägt nicht

The title check does not prove that the claim is in the paper; that needs reading the abstract (the tool prints the last abstract sentence with --kurz as an aid). References without PMID or DOI (software, web pages) are checked by hand.

Measured 2026-10-21 (Clara, Cle profile, test set clara-pruefstand/T24). Four cases against the tool itself: (A) invented PMID + invented title -> caught (WRONG, exit 1); (B) real PMID, title of a different paper -> caught (exit 1); (C) real PMID, matching title, but the sentence claims the OPPOSITE of what the abstract says (claimed a reduced stroke risk where the abstract reports an increased risk) -> passed with exit 0 and "3 correct, 0 wrong"; (D) reference with no PMID -> exit 2, "no references with PMID found" (correctly refuses to judge).

Case C is the blind spot: the tool checks identity (does this PMID carry this title), not the claim. A report can be 100 percent green and still misstate every source. The abstract check in step (3) of the rule stays manual work.

Bruchindikator

A report that passes the tool but whose claims are not in the cited abstracts. Measured instance: 2026-10-21, case C above — exit 0, "0 wrong", claim inverted relative to the abstract.

Ablesung

  • tool quellen-pruefen REPORT.md [--kurz] (2026-10-17): PubMed efetch title match (first 40 letters/digits), DOI registration via https://doi.org/api/handles/ (responseCode 1), exit 1 on any WRONG line
  • NCBI E-utilities: https://www.ncbi.nlm.nih.gov/books/NBK25501/ ; DOI handle API: https://www.doi.org/the-identifier/resources/factsheets/doi-resolution-documentation
