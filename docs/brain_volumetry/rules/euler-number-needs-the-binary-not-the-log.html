Aussage

The QC-relevant Euler number is that of the UNCORRECTED surface (surf/lh.orig.nofix, rh.orig.nofix), read with mris_euler_number. In FreeSurfer 8.2 the binary needs the ITK libraries (libitkvnl_algo-5.3.so.1) on LD_LIBRARY_PATH; without them it fails silently in a subprocess and a fallback that greps recon-all.log can pick the LAST "euler #" line, which is the topology-fixed surface (always 2). In the pilot this produced 6 sessions with Euler 2 and a wrong "recon-all pending" state; with the library path set, all 61 sessions had values between -142 and -15, cohort cutoff Q1 - 1.5 IQR = -109.5, no session flagged.

Traegt

Every QC gate built on the Euler number (Rosen 2018); every tool that wraps FreeSurfer 8 binaries from a conda Python.

Traegt nicht

FreeSurfer installations whose binaries find their libraries on the default path.

Bruchindikator

An Euler number of exactly 2 or an empty value for a finished session.

Ablesung
