Herkunft: QC gate of the DEMDAS pilot, 13.10.2026: 6 of 61 finished sessions reported Euler = 2 · eigene Seite · Markdown

Aussage

The QC-relevant Euler number is that of the UNCORRECTED surface (surf/lh.orig.nofix, rh.orig.nofix), read with mris_euler_number. In FreeSurfer 8.2 the binary needs the ITK libraries (libitkvnl_algo-5.3.so.1) on LD_LIBRARY_PATH; without them it fails silently in a subprocess and a fallback that greps recon-all.log can pick the LAST "euler #" line, which is the topology-fixed surface (always 2). In the pilot this produced 6 sessions with Euler 2 and a wrong "recon-all pending" state; with the library path set, all 61 sessions had values between -142 and -15, cohort cutoff Q1 - 1.5 IQR = -109.5, no session flagged.

Traegt

Every QC gate built on the Euler number (Rosen 2018); every tool that wraps FreeSurfer 8 binaries from a conda Python.

Traegt nicht

FreeSurfer installations whose binaries find their libraries on the default path.

Bruchindikator

An Euler number of exactly 2 or an empty value for a finished session.

Ablesung

13.10.2026 14:20-14:35, qc_gate.py before/after the LD_LIBRARY_PATH fix (61 sessions).

Aussage

Two list bugs produced 5 of 14 "failed" recon-all jobs in the DEMDAS HPC pilot (Slurm arrays 11179269/70, 13.10.2026):

  1. Empty TSV columns vanish with read. IFS=$'\t' read -r a b c ... collapses consecutive tabs, so a row with an empty run or pair field shifts every later column: recon-all received the DWI path as -i ("ERROR: cannot find ...dwi..."; array ids 49, 57, 64). Rule: parse each column with cut -f N (keeps empty fields) or in Python with csv.
  2. Two T1 files of the same visit under one id. A DEMDAS session can hold the distortion-corrected MPRAGE (run-2_T1w) and the uncorrected ND copy (_T1w, no run). The list treated them as two rows with the same id, so two jobs wrote into one working directory and destroyed each other (MRIsplineNormalize(): npeaks = 1, line-search failure). On the HPC copy only the ND file existed for the two sessions, and recon-all 8.1.0 failed on the ND image while Alita (8.2.0, run-2) succeeded. Rule: a "pair" is only run-1 + run-2 (two acquisitions); otherwise take exactly one T1, run-2 preferred, as gm_beispiel.py does.

A third failure class is a finding, not a bug: -FLAIRpial dies with "Numerical result out of range" in the vertex loop of mris_place_surface for 3 of 65 sessions whose base run succeeds (array ids 10, 44, 47). The base variant is kept for those.

Aussage

On a single machine, gate recon-all 8.x on the memory-heavy Synth phase (first ~15 min, 26 GB resident), not on the number of whole runs. Pattern: recon-all -autorecon1 behind a semaphore of floor((RAM - 10 GB) / 28 GB) slots, then -autorecon2 -autorecon3 unrestricted up to cores / threads. Expected gain on a 24-core, 62 GB box: 3.4 to ~7.5 sessions per hour (20 to ~9 days for 1616 DEMDAS sessions), same software, same numbers. On a cluster, submit one session per array task with the Synth-phase memory as the request (36 GB) and let the scheduler pack.

Trägt

  • FreeSurfer 8.0 to 8.2 recon-all on CPU; any T1w cohort large enough that days matter.
  • Resume semantics stay the same (lh/rh.thickness as the done criterion, stale done-marker removed).

Trägt nicht

  • recon-all 7.x (no heavy phase), FastSurfer (GPU segmentation), machines with RAM >= runs x 28 GB (gate is moot).
  • Longitudinal stream (-long): base and long steps have their own profile, measure first.

Bruchindikator

  • A batch with the phase gate that still produces OOM kills or no throughput gain over MAX_P=2 on the same box.
  • Status moves to "getragen" after the first full batch with measured throughput; to "gebrochen" if the gain is < 1.5x.

Kennzahlen: Mittel, Bias, SD der Differenz, Within-Subject-SD = SD/sqrt 2, CV %, ICC(2,1), SDC95 = 1,96 * sqrt 2 * SDw (kleinste Aenderung, die bei EINER Person als echt gelten darf), Bland-Altman-Plots. Ehrlich kennzeichnen, wenn das Paar kein echtes Scan-Rescan ist: dann ist es eine obere Schranke.

Aussage

  • There is exactly one head-to-head comparison of QC strategies at our scale: 12 strategies (2 manual, 5 automated: MRIQC, Qoala-T, global morphometry, Euler number, CNR; 5 semi-automated) applied to 259 FreeSurfer-processed scans, judged by the reduction of unexplained variance. Manual QC won; Euler number and MRIQC were the best automated substitutes; exclusion on global morphological outliers increased unexplained variance [1, Monereo-Sanchez 2021, Neuroimage, doi:10.1016/j.neuroimage.2021.118174, PMID 34000406]. Do not trim on volume outliers.
  • The Euler number is the best-validated cheap scalar: against 1840 manually rated T1w volumes it correlated with ratings across samples and separated "unusable" with AUC 0.98-0.99, and quality biased cortical thickness and age associations [2, Rosen 2018, Neuroimage, doi:10.1016/j.neuroimage.2017.12.059, PMID 29278774].
  • Off-the-shelf automated QC does not transfer for free: in 2438 T1w scans (11 sites, 39 scanner models, mean age 71) MRIQC and CAT12 accept/reject agreed with visual QC only at kappa 0.30 / 0.28 and varied strongly by dataset, while a classifier fitted on those same datasets reached 87.7% balanced accuracy (78.2% leave-one-site-out) [3, Bhalerao 2025, Imaging Neurosci, doi:10.1162/IMAG.a.4, PMID 40800787]. Supervised QC beats single metrics only after training on ratings of the same kind of data; Qoala-T reached AUC 0.98 in developmental data (784 rated scans) and transferred to two unseen datasets [4, Klapwijk 2019, Neuroimage, doi:10.1016/j.neuroimage.2019.01.014, PMID 30633965].
  • SynthSeg/SynthSeg+ do not remove the need for QC but supply segmentation-side signals: SynthSeg+ adds automated detection of faulty segmentations mainly caused by very low scan quality, shown on 14 000 clinical scans [5, Billot 2023, PNAS, doi:10.1073/pnas.2216399120, PMID 36802420]. The QC scores themselves can fail systematically: in 26k developmental scans only 36% of infant scans passed, and rescaling to adult brain size plus cropping to the adult field of view raised the pass rate to 91% (2803/3069) [6, Dorfschmidt 2026, bioRxiv, doi:10.64898/2026.07.22.739983, PMID 42539016]. Report pass rates per stratum, and treat a low pass rate as a fixable pre-processing bug before excluding subjects. This matches our own site-driven cortex pass rate.
  • Visual QC protocols are mature and shareable: EAGLE-I classifies region-level parcellation errors by type, size and direction and computes a per-brain rating (pass / minor / major / fail / discuss) [7, Deutscher 2025, MethodsX, doi:10.1016/j.mex.2025.103482, PMID 40791643]; a hands-on motion rating scale for FreeSurfer data with explicit exclusion rules [8, Backhausen 2016, Front Neurosci, doi:10.3389/fnins.2016.00558, PMID 27999528]; a paediatric protocol that drops single regions with major errors instead of the whole session [9, Pulli 2022, Front Neurosci, doi:10.3389/fnins.2022.874062, PMID 35585923].
  • Rater effort can be cut without dropping the human decision: a team-oriented visual QC pipeline built for low time cost (quick overlays, shared rating aggregation across pipelines and datasets) achieved mostly high inter-rater agreement on large structural and diffusion datasets [10, Kim 2025, PLoS One, doi:10.1371/journal.pone.0327388, PMID 40748971]. A documented subfield QC procedure with an error taxonomy had high between-rater reliability and manual correction contributed at most 3% error variance [11, Canada 2023, Hippocampus, doi:10.1002/hipo.23552, PMID 37246462]. In a survey of 37 investigators, 81% called QC very important but only 46% reported their QC procedure [12, Canada 2024, Hum Brain Mapp, doi:10.1002/hbm.70004, PMID 39450914] -- report it.
  • Editing is not free: manual edits reliably improve segmentation quality and reduce contrast-related bias [13, Wiskoski 2026, Neuroimage, doi:10.1016/j.neuroimage.2026.121831, PMID 41759954], but in 11 263 adolescent scans they reproducibly altered cortical thickness and strengthened age-thickness associations [14, Elyounssi 2025, Nat Neurosci, doi:10.1038/s41593-025-01990-7, PMID 40595447]. Record edit status (yes/no) and run a sensitivity analysis.
  • Longitudinal consistency is a QC measure in its own right: five hippocampal algorithms on ADNI 1-year data let only 50.8% (1.5 T) / 58.1% (3 T) of subjects pass stringent QC, produced implausible volume growth in 2.94-48.68% of subjects, and agreed on change only at ICC 0.319 / 0.149 [15, Sankar 2017, Hum Brain Mapp, doi:10.1002/hbm.23559, PMID 28295799]. FreeSurfer's longitudinal stream improved test-retest precision by 15-50% and the Euler number was a determinant of reliability [16, Rusinek 2026, Neuroimage, doi:10.1016/j.neuroimage.2026.121920, PMID 41966233].
  • Sizing the rated subsample is an explicit calculation, not a rule of thumb: sample size for agreement studies can be planned for a pre-specified lower and upper confidence limit of kappa, for any number of raters and categories, via the kappaSize R package [17, Rotondi 2012, J Clin Epidemiol, doi:10.1016/j.jclinepi.2011.10.019, PMID 22560852]. A 53-session rated page is a pilot: wide kappa CI, so report raw agreement and sensitivity/specificity per stratum, not kappa alone.
  • Quality biases downstream models and can do so invisibly: relaxing QC stringency shifted normative centiles of fetal brain MRI systematically, strongest in the outer centiles and often not visible at the segmentation level [18, Sanchez 2026, Imaging Neurosci, doi:10.1162/IMAG.a.1337, PMID 42609916].

Traegt

Design of a QC gate for a large segmentation run and for the reporting standard of the methods section: which automated measures to combine, why not to trim on volume outliers, how to size and stratify a rated subsample, and what the failure policy per failure type is.

Traegt nicht

Absolute thresholds (Euler cut-offs, kappa values, pass rates) are cohort specific; the kappa 0.30/0.28 and AUC 0.98 numbers come from different populations and cannot be copied to our data. Our own thresholds must be fitted on our own ratings [3,4].

Bruchindikator

A cohort study that shows volume-outlier trimming reducing measurement error, or a published SynthSeg QC score that is validated against human ratings in adult cohorts with a kappa clearly above the classifier values in [3].

Aussage

  • FD is computed by applying a box-counting / fractal estimator to a binary 3D mask of a segmented structure (cortical ribbon, WM volume, GM/WM boundary, pial surface, or an individual subcortical / parcellated region), typically after FreeSurfer segmentation and 3D reconstruction [1][6][16][22].
  • The natural analysis unit is a per-structure or per-parcellation binary volume; whole-brain, whole-cortex, lobar and single-subcortical-nucleus variants are all in use [1][3][19][20][22].
  • Scale / box-size range and estimator choice matter and must be fixed and reported: spatial-scale optimisation improves FD accuracy, and different estimators (e.g. correlation dimension vs others) differ substantially in reproducibility [6][16].
  • Reliability is generally good: intersession ICCs around 0.9–0.95 for the best-performing estimators, with FD and gyrification typically more reliable than cortical thickness [2][16].
  • FD is sensitive to image characteristics, not just to structure: image registration scheme, sequence weighting and spatial resolution significantly shift absolute FD values [6]; scanning protocol choice changes reliability [2].
  • FD frequently shows greater age- and disease-related sensitivity than volume for subcortical structures (notably caudate and thalamus) and greater sensitivity than cortical thickness or gyrification for age-related cortical differences [1][3][4].
  • In clinical work FD adds information beyond volumetry: in anti-LGI1 encephalitis (a Charité cohort) FD was reduced in fronto-temporo-parietal and subcortical regions and was often the more important measure in affected areas [8].
  • FD is usable longitudinally: linear mixed-effects models over up to 3 visits in anti-LGI1 encephalitis detected regional FD change [8], and a multi-site age-prediction study shows cross-site structural measures are systematic enough for individual-level modelling [5].
  • For our 600-patient multi-centre cohort the main threats are site/scanner and registration effects on absolute FD; a fixed processing pipeline plus site harmonisation and reliability checks are mandatory [6][2].

Practical recommendation (as written for our setup)

FreeSurfer 8 recon-all + longitudinal stream, multi-centre 3T stroke cohort, ~600 patients, up to 4 sessions over 5 years.

  1. Compute FD on FreeSurfer output with a fixed, reported estimator. Segment with the longitudinal stream, build binary masks per cortical parcellation and per subcortical structure, and run a box-counting / fractal estimator on those masks. Follow the retrieved practice of FreeSurfer segmentation plus an FD toolbox (calcFD is the one named in the literature) [1][19][20]; a whole-brain/skeleton 3DFD box-counting alternative exists [17].
  2. Fix the scale range and the estimator, and state them in the methods. Do not use defaults: optimise the spatial scale in simulations/phantoms first [6], and prefer the estimator with the highest within-subject reproducibility (correlation dimension performed best, ICC 0.9–0.95) [16]. Report box sizes and estimator explicitly — heterogeneity in these choices is the main reason the systematic review cannot pool results [7].
  3. Treat registration as a first-class confound. Unbalanced registration shifts absolute FD and produces spurious associations; re-register consistently and verify no deviation clusters around the registration target [6]. Keep the FreeSurfer longitudinal template-based processing uniform across sessions and sites.
  4. Run an in-study reliability/QC check. You have repeated sessions (up to 4 over 5 years) — use them to compute intersession ICCs for FD per structure, mirroring the test-retest literature [2][16], and drop structures with poor reproducibility.
  5. Harmonise across sites and model site explicitly. Multi-centre FD is affected by image characteristics [6]; a cross-site design is feasible (1056-adult multi-site age prediction worked) but site must enter the statistical model [5]. Harmonisation of FD itself (e.g. ComBat) is unverified in the retrieved literature and should be validated internally before use.
  6. Always report FD alongside volume and thickness. FD adds independent information and is often more sensitive, but they index distinct structure aspects [1][3][4]; reviewers expect all three [7].
  7. Use longitudinal mixed-effects models with age (FD is non-linearly age-dependent [15]) and disease duration as predictors, as done in the Charité anti-LGI1 study [8].
  8. Expect region-specific effects, not a global FD drop. Clinical FD differences are regional [8][11][12][21][22]; plan a parcellated/hierarchical analysis with multiple-comparison control rather than one whole-cortex number.

Aussage

  • White-matter lesions are not a cosmetic problem: they are misclassified as grey matter (or vice versa) during intensity-based segmentation, which biases GM/WM volumes and cortical thickness [1][2][3][6][11].
  • The bias is size- and contrast-dependent: it grows with lesion volume and is worst when lesion intensity is close to the GM/WM interface [1][2][3].
  • Merely masking lesions out does not remove the bias; only replacing the lesioned voxels with plausible tissue intensities (filling / inpainting) restored accurate tissue-class measurements [2].
  • Filling with normal-appearing WM intensity (LEAP, FSL lesion_filling) reduced simulated GM/WM volume errors from ~2.3% / ~3.6% to ~0.1% [1]; the FSL/LST family is the standard building block in clinical pipelines [2][7][26] (unverified: [1] supports the error reduction, but no abstract shows that FSL/LST is the standard building block of clinical pipelines - that part is an inference from [2][7][26] using it).
  • Filling is not universally beneficial: in MS, FreeSurfer volumetry was essentially unchanged by filling, while FSL-SIENAX and SPM changed, and inter-scanner reproducibility differed between packages [7][8].
  • Filling can introduce artefacts that scale with lesion load (r = 0.84 with total lesion volume) and therefore needs quality control, especially at high lesion load [33].
  • Patch-based and deep-learning inpainting (NiftySeg/Prados, FastSurfer-LIT, MSRepaint, VBG) replaces lesions with plausible texture instead of a flat WM intensity and outperforms simple filling on downstream parcellation [5][17][18][21].
  • WMH specifically bias FreeSurfer subcortical GM volumes (caudate, putamen, thalamus, pallidum, accumbens) in a systematic, age- and diagnosis-dependent way; correcting for WMH changed the direction of age and AD effects [11]. WMH should therefore be corrected or explicitly accounted for, not ignored [11][36].
  • Modern tools partly handle lesions natively: SAMSEG has an explicit WMH/lesion model [14][15] and SynthSeg is contrast- and resolution-robust and needs no retraining [13]. Neither the SynthSeg nor the SynthSeg+ abstract mentions a lesion class (unverified as a negative claim — the abstracts simply do not describe one), so filling remains the safer route for lesion-adjacent volumetry.
  • Masking (rather than filling) at the level of cortical-thickness estimation is the better strategy when cortical thickness is the endpoint: masking lesion voxels from CT computation significantly attenuated lesion-induced bias in TBI [12].
  • No single method is correct for all endpoints; for longitudinal stroke cohorts the defensible practice is: run lesioned and lesion-free versions, apply one fixed, documented pipeline, and report the sensitivity of the result to the lesion-handling choice [7][8][12][14].

Practical recommendation (as written for our setup)

Our setup: infarcts filled by mirroring, WMH by FSL lesion_filling, thresholds 1 ml (infarct) / 10 ml (WMH).

  1. Mirroring for infarcts is defensible and has a long lineage - virtual brain transplantation filled the lesion from the non-stroke hemisphere before FreeSurfer surface reconstruction [38], and modern variants (VBG [17], FastSurfer-LIT [18], MSRepaint [21]) are essentially automatic, QC-able versions of the same idea. Keep mirroring, but verify it does not duplicate healthy tissue across the midline for lesions touching midline structures or crossing the falx; those need patch-based or diffusion inpainting instead [5][18].
  2. Keep FSL lesion_filling for WMH: it is the classical, reproducible implementation of the "refill with normal-appearing WM" principle that removed the segmentation bias in the foundational simulation studies [1][2], and it remains the reference against which newer inpainting is benchmarked [21].
  3. Thresholds: the retrieved literature does not support a hard volume cut-off. The bias is continuous in lesion volume and worst near the GM/WM intensity interface [2][3]; a 1 ml / 10 ml rule is a pragmatic save-compute choice, not a bias-free boundary. For subjects just below the threshold the systematic error is still present - report it as a sensitivity analysis rather than treating those scans as clean.
  4. Because filling can introduce artefacts that scale with lesion load (r = 0.84) [33], add a QC step (difference image before/after filling; check for rasterisation, spurious edges near CSF and deep GM) and exclude subjects whose filling QC fails rather than silently carrying artefacts. Note also the cautionary result that filling can reduce parcellation accuracy for small lesions in FastSurfer [29] - filling small lesions is not automatically an improvement.
  5. For volumetry in these subjects, prefer a pipeline that tolerates lesions: SAMSEG (explicit WMH model, FreeSurfer-integrated [14][15]) or SynthSeg/SynthSeg+ on the filled image for whole-brain and ICV [13][19]. Do not switch segmentation engines between arms or between time points: engine choice changes volumes more than filling does [7][8][16].
  6. For cortical-thickness endpoints after stroke, prefer masking lesion voxels from CT estimation (not only from summarisation) - this was the only variant that significantly attenuated the bias in the closest available analogue (contusions in TBI) [12].
  7. For WMH volume itself, report at least one cross-check: WMH-SynthSeg on T1 (good T1-only performance in stroke [23]) or SAMSEG (multi-site-robust [22][35]) alongside the FSL/BIANCA-based numbers, and state which is the primary measure.

Aussage

  • FreeSurfer aseg, SynthSeg/SynthSeg+, FastSurfer, SAMSEG and FSL FIRST are all usable for the large structures (whole hippocampus, striatum, thalamus, brainstem); the choice is decided less by peak accuracy than by longitudinal use, lesion handling and site harmonisation [1,2,3,4,5,6,7,8,10].
  • For a longitudinal cohort the decisive step is processing all sessions through one unbiased within-subject template (FreeSurfer longitudinal stream) or an equivalent longitudinal registration; treating sessions independently injects processing variance into the change signal [7,27].
  • Lesion filling of T1 is sensible before any T1-based segmentation, but in the one retrieved head-to-head test lesion filling did not change between-scanner and within-scanner agreement for the six tested tools; the residual scanner effect was the larger problem [6].
  • Reported smallest detectable change (SDC) is small within a scanner (1.0% for SAMSEG whole brain) but much larger between scanners (4.8% for SynthSeg thalamus up to 29.3% for CAT12 thalamus), which is the real limit on detecting atrophy [6].
  • Accuracy checks against manual tracing show automated packages systematically overestimate basal-ganglia and thalamic volumes; the pallidum and thalamus are the weakest structures, and errors are worst for the smallest volumes [4].
  • Hippocampal subfields and amygdalar nuclei are only reliable above roughly 200–300 mm3 per structure (unverified); small nuclei such as fimbria and hippocampal fissure have ~15% reproducibility error [11,12].
  • Thalamic nuclei need a dedicated atlas (optionally with diffusion MRI); they are not a standard output of the general packages [13,14].
  • Harmonisation is not optional: all retrieved harmonisation studies show large site or scanner effects in volumetric and cortical measures, and ComBat/longComBat remove them while preserving biological variance; longComBat is more powerful for longitudinal change than cross-sectional ComBat [15,16,17,18].
  • Automatic QC flags exist (SynthSeg+ faulty-segmentation detection, MRIQC/Qoala-T style outlier metrics), but manual inspection of a sample remains necessary; manual editing of surfaces changes subcortical volumes substantially [3,10,19].
  • The specific claim that SynthSeg underestimates hippocampal atrophy is unverified in the retrieved literature; plausible mechanisms below, but it must be tested in-house against the FreeSurfer longitudinal stream before it is accepted as fact [6,11,12].

Practical recommendation (as written for our setup)

Given the retrieved evidence and the existing SynthSeg + FreeSurfer 8.x local setup, I recommend a two-track pipeline with a single primary analysis track and a cross-check.

Primary track (volumetric readout for group statistics over time): 1. Build one unbiased within-subject template per patient from all available sessions and process every session against it (FreeSurfer longitudinal stream, or an equivalent unbiased longitudinal registration). This is the step that most directly reduces the processing variance that currently mixes into the change signal [7,30]. 2. Use lesion-filled T1 for segmentation, but do not expect lesion filling to remove scanner effects; it addresses lesion-driven, not site-driven, variance [6,23]. Keep the FLAIR-based lesion masks under a validated segmenter for the lesion maps themselves [32]. 3. Keep SAMSEG (lesion-aware variant) as the primary T1 segmenter for the basal ganglia, thalamus and brainstem. Justification: it was the most repeatable within scanner in the 3 T multicentre test (whole brain SDC 1.02%), is sequence-adaptive and protocol-robust, and has a lesion-aware mode (unverified); it also delivered among the best between-scanner SDC for thalamus with SynthSeg [6,8,9]. 4. Keep the FreeSurfer longitudinal stream (or FastSurfer-long) in parallel as the reference segmentation for the same structures, because it is the best-validated longitudinal framework and enables the hippocampal-subfield branch [7,12,27]. 5. Derive harmonisation from the raw volumes: apply longitudinal ComBat with scanner/ site as batch and age/interval as covariates, and fit it on a training split. Cross-sectional ComBat is an acceptable fallback, but expect lower power for change; and if ComBat is fitted without training data it may fail to recover atrophy, so always check that harmonisation preserves the expected atrophy contrast [17,18]. 6. Report structures only where the retrieved reliability evidence supports them: whole hippocampus, striatum, thalamus, brainstem and larger amygdala volumes are the robust core; hippocampal subfields above ~300 mm3 and amygdalar nuclei above ~200 mm3 only if the cohort-specific test-retest supports them; fimbria and hippocampal fissure should not be primary endpoints [4,11,12,27]. 7. Do not use thalamic nuclei as a primary endpoint in this cohort unless diffusion MRI is available and a nuclei-specific atlas is deployed; they are not a standard output of the general tools and their reliability thresholds are stricter still [13,14].

Cross-check track (this directly addresses the observed underestimation): 8. On 20–30 patients, run FreeSurfer-long, SAMSEG and SynthSeg side by side on the same lesion-filled, template-registered T1s and compare the annualised percentage change of hippocampal volume, not the cross-sectional volumes. Report the tool-specific SDC and compute whether each tool can separate patients with expected decline from stable patients. Use the within-scanner versus between-scanner SDC decomposition from [6] as the template for this analysis. 9. Treat the "SynthSeg underestimates hippocampal atrophy" statement as a hypothesis to test, because no retrieved abstract states it. The retrieved facts that make it plausible are: SynthSeg has no learned spatial prior (unverified), so it cannot regularise a partly lesioned or low-contrast anterior hippocampus [2]; most hippocampus methods over-segment at the anterior border and degrade on clinical data [11]; and hippocampal-subfield reliability is strongly volume-dependent, so small structures carry the largest error [12,27]. 10. Regardless of the chosen segmenter, run automatic QC (SynthSeg+ faulty-segmentation flag plus an MRIQC/Qoala-T-style outlier pass on global measures, Euler number and CNR) and manually review the flagged scans; a semi-automated strategy was the best-performing one in the retrieved QC comparison (unverified), and manual editing moves subcortical volumes substantially [3,19].

If the group is willing to invest in task-specific training, a fine-tuned nnU-Net (or an ensemble) on locally traced stroke data is the most promising route to a single lesion-robust segmenter, based on the nnU-Net benchmark and the successful task-specific brainstem and single-contrast MS models [21,23,24]; a local training set of even a few dozen traced cases is a realistic starting point.

Abstract-level evidence only (no full texts read); a literature map, not a systematic review. Open questions:

  • No retrieved study measured hippocampal atrophy rate with SynthSeg against the FreeSurfer longitudinal stream in a stroke cohort; the head-to-head evidence is from MS and from cross-sectional accuracy benchmarks. This gap is the core of the local observation and should be closed with the cross-check track in section 4.

  • WMH effects on segmentation are documented but the best correction method is explicitly left open by the retrieved paper [22].
  • Ventricle enlargement is not separately quantified in the retrieved abstracts; its interaction with basal-ganglia and thalamic segmentation in stroke is unverified from this evidence base.

  • Thalamic nuclei and hippocampal subfield reliability in the presence of basal-ganglia infarcts specifically was not found in the retrieved literature.

Part A: the study and our pipeline

1. What DEMDAS is

The cohort we call DEMDAS is the German multicentre stroke cohort published as DEDEMAS, the Determinants of Dementia After Stroke study. The protocol paper by Wollenweber and colleagues describes a prospective observational study of 600 patients with an acute stroke and no dementia before the stroke [1]. The patients receive multimodal imaging (magnetic resonance imaging, and in part positron emission tomography of glucose metabolism and of amyloid, plus imaging of the retina), blood and cerebrospinal fluid biomarkers, and detailed cognitive testing. Follow-up lasts five years, and the main outcome is dementia after stroke. The study is registered as NCT01334749 [1].

Note on the name: in our folders and in earlier documents the study is written DEMDAS, and one earlier primer expanded it as "DZNE Mechanisms of Dementia After Stroke". The published name is DEDEMAS, Determinants of Dementia After Stroke [1]. In the meeting, say "the DEDEMAS stroke cohort".

Two later papers from the same cohort help you explain the clinical side. Among stroke survivors with mild cognitive impairment after stroke, positivity on amyloid positron emission tomography was rare (about 5 percent), which suggests that the cognitive problems after stroke are mostly not caused by Alzheimer pathology [2]. Telephone versions of cognitive screening tests were validated against detailed testing in the same cohort [3].

Why the study matters. About one in ten patients already has dementia before a first stroke, about one in ten develops new dementia soon after a first stroke, and more than one in three after a recurrent stroke [4]. Imaging is used to find out which brain changes predict this decline.

2. The imaging data we hold

The imaging set is organised in BIDS (Brain Imaging Data Structure), a standard folder and file naming scheme. Each participant has up to four sessions, named by months after the stroke: M0 (baseline, the acute phase), M6, M36 and M60. The scans are three tesla Siemens examinations from several sites. The series that matter:

  • T1-weighted MPRAGE (magnetisation prepared rapid gradient echo), 1 millimetre isotropic. This is the anatomical image: grey matter is darker than white matter, cerebrospinal fluid is black. All volumetry and cortical thickness come from it.
  • FLAIR (fluid attenuated inversion recovery). A T2-weighted image in which the water signal of the cerebrospinal fluid is suppressed, so lesions in the white matter appear bright. Used for white matter hyperintensities and old infarcts.
  • DWI (diffusion weighted imaging) with the trace image and the ADC (apparent diffusion coefficient) map. Acute infarcts are bright on DWI and dark on ADC, because water movement is restricted in dying cells. In this cohort the diffusion sequence was acquired with several gradient directions (about 30 directions at one b-value in the series we checked), so in principle a diffusion tensor could be fitted, if the raw diffusion data are available and not only the scanner-derived maps. This needs checking.
  • T2* or SWI-like gradient echo images at some sites, which show microbleeds and iron.

The earlier primer lists the counts of participants and sessions in our copy [see demdas-volumetry-primer-2026-10-13].

3. Our processing pipeline, step by step

Think of the pipeline as turning each T1 image into numbers per brain structure, while making sure that stroke lesions do not distort those numbers.

Step 1: lesion masks. Acute infarcts at baseline are segmented automatically from DWI, ADC and FLAIR with DeepISLES, an ensemble of the best methods of the ISLES 2022 challenge (Ischemic Stroke Lesion Segmentation; reference not yet checked, marked unverified). White matter hyperintensities get their own masks. Infarct masks are carried over to later sessions.

Step 2: lesion filling. A lesion inside the white matter has a grey-matter-like intensity on T1. Segmentation software then mistakes it for grey matter or cerebrospinal fluid, and volumes become wrong. Simply masking the lesion out does not fix this; replacing the lesion voxels with intensities of the surrounding normal-appearing white matter does [5]. We fill white matter hyperintensities this way (FSL lesion_filling). For infarcts we use a mirror fill: the lesion is replaced by the mirrored tissue of the healthy hemisphere. Filling is applied only where the lesion load is high enough to matter (infarct at least 1 millilitre, white matter hyperintensities outside the infarct at least 10 millilitres), because small loads had no measurable effect in our tests.

Step 3: SynthSeg. SynthSeg is a deep learning segmentation tool from the FreeSurfer team that was trained only on synthetic images with randomised contrast and resolution. It therefore works on scans of any contrast and resolution without retraining [6]. The robust version adds cortical parcellation, intracranial volume and automatic quality control, and reproduced known ageing atrophy patterns in 14,000 clinical scans [7]. It gives volumes of about 30 structures per session in minutes.

Step 4: FreeSurfer recon-all. FreeSurfer reconstructs the cortical surface from the T1 image and models most brain structures [8]. From the surfaces it computes cortical thickness, surface area and folding per region. One session takes about an hour. We run it on the Charité high performance computing cluster as a job array.

Step 5: the longitudinal stream. Instead of analysing each session on its own, FreeSurfer builds an unbiased within-subject template from all sessions of a person and initialises every session from it. This treats all time points identically and makes changes over time more precise [9]. This is what you want for atrophy rates after stroke.

Step 6: quality control and statistics. Every session is checked visually in our viewers (overlay switch, lesion panel), and the Euler number of the surfaces is used as an automatic quality measure. For every trend we also report measurement error: test-retest agreement, intraclass correlation coefficient and the smallest detectable change (see Part E).

One sentence to say in the meeting: "We take the T1 images of the DEDEMAS stroke cohort, segment and fill the stroke lesions, and then run SynthSeg and the FreeSurfer longitudinal stream on the cluster, with quality control and measurement error for every structure."

4. Small vessel disease: the vocabulary of the stroke side

Small vessel disease means damage to the small arteries, arterioles, capillaries and venules of the brain. Its imaging markers were standardised in the STRIVE recommendations (Standards for Reporting Vascular changes on nEuroimaging) [10] and updated in STRIVE-2 [11]:

  • Recent small subcortical infarct: a small fresh infarct in the territory of one perforating artery.
  • Lacune: a small fluid-filled cavity, the late stage of a small infarct or bleed.
  • White matter hyperintensities: bright areas on FLAIR and T2 in the white matter, of presumed vascular origin. Their severity is often graded with the Fazekas scale, which goes back to Fazekas and colleagues in 1987 [12].
  • Cerebral microbleeds: small round dark dots on T2* or SWI (susceptibility weighted imaging), caused by old blood (haemosiderin) [13, 14]. They can be rated with the Microbleed Anatomical Rating Scale [13].
  • Perivascular spaces: fluid-filled spaces around vessels, bright on T2 like cerebrospinal fluid.
  • Brain atrophy: loss of brain tissue, visible as larger ventricles and sulci, measured as volumes.

Part B: what Carsten Finke works on

5. Autoimmune encephalitis in plain words

Autoimmune encephalitis is an inflammation of the brain in which the immune system makes antibodies against proteins of the nerve cells, often against receptors or channels at the synapse. The patients develop memory problems, psychiatric symptoms, seizures, movement disorders or sleep disorders. A clinical approach to diagnosis defines possible, probable and definite autoimmune encephalitis, so that treatment can start before the antibody result is known [15]. The most important antibody types in his papers:

  • NMDA receptor encephalitis (N-methyl-D-aspartate receptor). Mostly young women; psychiatric symptoms, memory loss, seizures. Routine MRI is often normal.
  • LGI1 encephalitis (leucine-rich glioma-inactivated 1). Mostly older men; limbic encephalitis with memory loss and characteristic brief seizures; the hippocampus is affected.
  • CASPR2 encephalitis (contactin-associated protein-like 2). Variable: cognitive decline, seizures, nerve hyperexcitability, pain.
  • IgLON5 disease. Sleep disorder, movement problems and swallowing problems, with a tau pathology in the brainstem.
  • GABA-A and GABA-B receptor encephalitis, MOG antibody disease (myelin oligodendrocyte glycoprotein) and NMOSD (neuromyelitis optica spectrum disorder with aquaporin-4 antibodies) appear as related neuroimmunological diseases.

Treatment is immunotherapy (steroids, plasma exchange, immunoglobulins, rituximab). Many patients recover in their daily function, but memory and psychiatric problems often remain. Finding the brain changes behind these remaining symptoms is the main theme of his imaging work.

6. His imaging methods

a) Volumetry and fractal dimensionality from T1. Volumes come from FreeSurfer, as in our pipeline. Fractal dimensionality (abbreviated FD) is a single number that describes how complex the folded cortical surface is. A smooth surface has a fractal dimension close to 2, a strongly folded one is higher. It was shown to be more sensitive to ageing than cortical thickness or gyrification [16], and the choice of the spatial scale range matters for reliable values [17]. In LGI1 encephalitis (34 patients, up to three visits), fractal dimensionality was reduced in fronto-temporo-parietal cortex and subcortical regions, was more often the more important measure than volume, and was related to clinical and cognitive outcome [18]. In NMDA receptor encephalitis (70 patients and 70 matched controls), fractal dimensionality from T1 was combined with normative modelling and with outcomes; two thirds of the patients still had symptoms, mostly memory and psychiatric [19]. Important for you: when Matthias wrote "FD", this most likely means fractal dimensionality, not a diffusion measure.

b) Diffusion tensor imaging. Diffusion tensor imaging fits a small 3 by 3 matrix (the tensor) to the diffusion signal in every voxel. Its main directions give the direction of nerve fibres, and its values give how freely water moves [20]. From it come fractional anisotropy (FA, how strongly diffusion prefers one direction, high in intact fibre bundles) and mean diffusivity (MD, overall water mobility, rises when tissue is damaged). NODDI (neurite orientation dispersion and density imaging) uses two diffusion shells to separate neurite density from fibre dispersion, the two things that FA mixes [21]. In NMDA receptor encephalitis, Finke found widespread white matter changes on diffusion tensor imaging, strongest in the cingulum and related to disease severity, while routine MRI and grey matter were normal [22]. In LGI1 encephalitis he found hippocampal atrophy and abnormal hippocampal microstructure (mean diffusivity and FA) with persistent memory deficits [23], and later, with probabilistic tractography and network analysis, a reduced and reorganised white matter network linked to memory, attention and executive deficits despite immunotherapy [24].

c) Resting-state functional MRI and connectivity. Functional connectivity is the correlation over time of the BOLD signal (blood oxygen level dependent) between brain regions while the person rests in the scanner. In NMDA receptor encephalitis, hippocampal functional connectivity was reduced and predicted memory performance [22].

d) Animal models. Patient-derived monoclonal antibodies are injected into mice or rats, and the animals are scanned on the experimental 7 tesla MRI of the Charité. Mice with human NMDA receptor antibodies showed reduced hippocampal functional connectivity, similar to patients [25]. Human CASPR2 antibodies caused reduced resting-state connectivity in mice without short-term structural change [26]. He is also co-author of a mouse connectome pipeline in a model with vascular dementia features, which showed lacunar infarcts, microbleeds and progressive white matter change over six months [27].

e) His own summary of the field. In a 2026 review he writes that conventional MRI is indispensable for diagnosis, that atrophy over time reflects cumulative damage and outcome better than acute lesions, that volumetry and simple quantitative measures are closest to clinical use, and that advanced methods such as quantitative MRI, diffusion tensor imaging and resting-state functional MRI still need standardisation and validation [28].

Part D: glossary

  • ADC (apparent diffusion coefficient): map of water mobility from DWI; dark in acute infarcts.
  • Amyloid PET: positron emission tomography that shows amyloid plaques, a sign of Alzheimer pathology.
  • Atrophy: loss of brain tissue over time.
  • b-value: strength of the diffusion weighting in a diffusion scan.
  • BIDS (Brain Imaging Data Structure): standard for naming and organising imaging files.
  • BOLD (blood oxygen level dependent) signal: the signal measured in functional MRI.
  • CASE (Clinical Assessment Scale in Autoimmune Encephalitis): severity score for encephalitis patients.
  • Cerebrospinal fluid (CSF): the clear fluid around and inside the brain.
  • Cingulum: a white matter bundle along the medial surface of the brain, part of the memory network.
  • Cortex, cortical ribbon: the outer layer of grey matter; the ribbon is its 3D band between white matter and the pial surface.
  • Cortical thickness: distance between the white matter surface and the pial surface, in millimetres.
  • DeepISLES: ensemble of deep learning models from the ISLES 2022 challenge for acute infarct segmentation (reference unverified here).
  • DEDEMAS: Determinants of Dementia After Stroke study; our "DEMDAS" cohort [1].
  • Dice coefficient: overlap between two segmentations, from 0 (none) to 1 (identical).
  • DTI (diffusion tensor imaging): model of water diffusion per voxel; gives FA and MD [20].
  • DWI (diffusion weighted imaging): MRI sensitive to water movement; bright in acute infarcts.
  • Euler number: topological measure of a reconstructed surface; many defects mean poor quality.
  • FA (fractional anisotropy): 0 to 1, how directional water diffusion is; lower when fibres are damaged.
  • Fazekas scale: grading of white matter hyperintensity severity [12].
  • FD (fractal dimensionality): complexity of the cortical folding; in Finke's recent papers this is what FD means [18, 19].
  • FLAIR: T2-weighted MRI with suppressed fluid signal; lesions appear bright.
  • FreeSurfer: software suite for cortical surface reconstruction, thickness and volumes [8].
  • Functional connectivity: correlation of BOLD signals between regions over time.
  • Grey matter, white matter: grey matter holds the nerve cell bodies (cortex and deep nuclei); white matter holds the connecting fibres.
  • Haemosiderin: iron-containing breakdown product of blood; makes microbleeds dark on SWI.
  • Hippocampus: structure in the medial temporal lobe essential for memory; often affected in LGI1 encephalitis.
  • Immunotherapy: treatments that suppress or modulate the immune system.
  • Infarct: area of dead tissue after loss of blood supply (ischaemic stroke).
  • Intracranial volume (ICV): volume inside the skull; used to correct brain volumes for head size.
  • Lacune: small fluid-filled cavity after a small infarct.
  • Lesion filling: replacing lesion voxels with normal-appearing tissue intensities before segmentation [5].
  • LGI1, NMDAR, CASPR2, IgLON5, GABA-A/B, MOG, AQP4: target proteins of the antibodies in different autoimmune diseases (see section 5).
  • Limbic encephalitis: encephalitis focused on the limbic system (hippocampus, amygdala).
  • Longitudinal stream: FreeSurfer processing that uses a within-subject template for several sessions [9].
  • MD (mean diffusivity): average water mobility; higher when tissue is damaged.
  • Microbleed: small chronic bleed, dark dot on T2* or SWI [13].
  • MPRAGE: the standard T1-weighted 3D sequence on Siemens scanners.
  • mRS (modified Rankin Scale): 0 (no symptoms) to 6 (dead), disability after stroke or encephalitis.
  • NODDI: diffusion model for neurite density and orientation dispersion [21].
  • Normative modelling: modelling the healthy range of a measure, then scoring each patient as a deviation from it [29].
  • Parcellation: dividing the cortex into named regions (atlas).
  • Perivascular space: fluid-filled space around a small vessel.
  • Probabilistic tractography: reconstruction of likely fibre pathways from diffusion data.
  • Resting-state fMRI: functional MRI without a task.
  • Small vessel disease: disease of the small brain vessels; markers in STRIVE [10, 11].
  • STRIVE, STRIVE-2: standards for imaging research in small vessel disease [10, 11].
  • SWI (susceptibility weighted imaging): MRI sensitive to iron, blood and veins [14].
  • SynthSeg: contrast-agnostic deep learning segmentation [6, 7].
  • T1, T2, T2: basic MRI contrasts; T1 for anatomy, T2 and FLAIR for lesions, T2 and SWI for blood and iron.
  • Tesla (T): field strength of the scanner; clinical 1.5 or 3 T, research 7 T.
  • Voxel: the 3D pixel of an MRI image, for example 1 by 1 by 1 millimetre.
  • White matter hyperintensity (WMH): bright white matter area on FLAIR, mostly from small vessel disease.

Part E: statistics you will meet in his papers

  • Propensity score matching: each patient gets a healthy control with a similar probability of being a patient given age and sex; makes groups comparable [19, 24].
  • Linear mixed-effects model: regression for repeated measures; each person gets their own intercept (and slope), so several visits per person can be analysed together [18].
  • Dominance analysis: decides which of several correlated predictors (here volume or fractal dimensionality) explains more of an outcome [18].
  • Normative model and z-score: a patient's value expressed as standard deviations from the healthy expectation for their age and sex [19, 29].
  • Effect size (Cohen's d): difference between groups in units of standard deviation; 0.2 small, 0.5 medium, 0.8 large.
  • Intraclass correlation coefficient (ICC): agreement of repeated measurements, 0 to 1; above 0.9 is excellent.
  • Smallest detectable change (SDC95): the change that exceeds measurement error with 95 percent confidence; 1.96 times the square root of 2 times the within-subject standard deviation.
  • Multiple comparison correction: when testing many brain regions, p-values are corrected (for example false discovery rate) to avoid false positives.

2. What we measure and why

  1. Tissue and structure volumes per session: total grey matter (cortex + subcortical + cerebellum), cortex, subcortical GM, white matter, CSF and ventricles, plus nine focus structures (hippocampus, amygdala, entorhinal and parahippocampal cortex, thalamus, caudate, putamen, pallidum, accumbens, ventral diencephalon), left and right, in ml and in % of intracranial volume (ICV).
  2. Cortical thickness per session: mean thickness per hemisphere and 34 Desikan-Killiany regions per hemisphere, in mm, from FreeSurfer surfaces.
  3. Lesions: acute/chronic infarct masks (DeepISLES on DWI at M0; MAPPING on T1 for follow-ups) and white-matter hyperintensity (WMH) volume from an in-house 3D U-Net. Infarcts are excluded from the tissue classes after segmentation (variant C, user decision 2026-10-10/11); WMH is reported as its own quantity and no longer shown on the GM QC page (user decision 2026-10-13).
  4. Change over time: slopes per participant and mixed-model slopes per structure, in % per year, and the question whether a change in one person is larger than the measurement error (detectability).

Why these: post-stroke cognitive decline is tied to atrophy of hippocampus, thalamus and cortex, to ventricular enlargement and to WMH growth; the imaging task is to measure those reliably in the presence of infarcts.

4. Method background you must be able to explain

SynthSeg [5] is a 3D U-Net trained only on synthetic images generated from label maps with random contrast, resolution and artefacts, so it segments any MRI contrast without retraining. --robust uses a two-step network for clinical-quality scans; --parc adds the Desikan-Killiany cortical parcellation; the QC score per structure is the network's own agreement estimate (0 to 1). It runs on the CPU inside FreeSurfer 8.2 (the bundled TensorFlow has no GPU build): 85-99 s per 1 mm image, peak RSS 19.2 GB per process (measured 2026-10-13).

FreeSurfer recon-all [1,2] builds surfaces: intensity normalisation, skull strip, white-matter segmentation, tessellation of the WM surface, topology correction, deformation to the white and pial surfaces, inflation, spherical registration to an atlas, parcellation. Cortical thickness is the distance between the white and pial surfaces at each vertex, averaged per region. The Euler number of the initial surface (?h.orig.nofix) counts topological defects: 2 - 2 × holes; more negative means more defects and is the best automated predictor of a bad segmentation [15,16]. FreeSurfer 8 replaced several classical steps by deep-learning modules (SynthSeg, SynthMorph, SynthStrip), which is why a run takes 45 minutes instead of 4-7 hours but needs 17-28 GB of RAM.

Longitudinal stream [3]: for each participant a within-subject template ("base") is built from all time points and each time point ("long") is then initialised from that template, so that processing is unbiased with respect to time point and random variation across time points shrinks. In 11 datasets the cross-sectional stream was about 0.25 ICC lower for change than the long stream [7].

Lesion filling [10-12] replaces lesion voxels in the T1 with white-matter-like intensities before segmentation so that WM lesions are not labelled grey matter or CSF; masking alone does not remove the bias [11]. For cortical or cavitary infarcts filling with WM intensity is wrong; inpainting (FastSurfer-LIT [14]) or masking is used there.

Measurement error (section 5): within-subject SD from paired measurements, ICC(2,1) for absolute agreement, and the smallest detectable change SDC95 = 1.96 × √2 × SD_within, the change that exceeds measurement noise in a single person with 95 % confidence.

ComBat / longComBat [21-23]: empirical-Bayes location-scale harmonisation of ROI tables across scanners, protecting covariates of interest; the longitudinal variant models subject-specific intercepts.

8. Why FreeSurfer as the main tool, and how to improve from here (literature, PMID-verified 2026-10-13)

Ordered by expected gain for this cohort:

  1. Longitudinal stream for the 465 participants with follow-up; baseline-only participants as one-time-point bases so processing is identical. Evidence: +0.25 ICC for change versus cross-sectional [7]; the 0-6-month contrast is noise, rates come from 0/36/60 months [7].
  2. Lesion handling before recon-all: fill WM lesions (WMH + WM infarcts) with FSL lesion_filling [10-12]; cortical / cavitary infarcts by inpainting (FastSurfer-LIT [14], not yet validated on infarcts) or masking; always exclude lesion-overlapping vertices and voxels from ROI statistics. In chronic stroke / SVD a lesion-aware FreeSurfer procedure cut tissue-segmentation failures from 62 % to 8 % [13].
  3. FLAIR-assisted pial surface (-FLAIRpial): plausible, no quantitative study found; test on 30-40 sessions against Euler number, edit need and SDC95.
  4. QC gate per session: Euler number per site [15,16], MRIQC [18], recalibrated Qoala-T [17]; motion proxy as covariate (motion lowers GM and thickness by about 0.7 % per mm/min [20]).
  5. Local test-retest from the 40 same-session repeat T1 pairs: the cohort's own SDC95 per ROI, used as the threshold for implausible within-subject jumps.
  6. longComBat on the ROI tables across the 7 sites, protecting age, sex, group and lesion load [21,23].
  7. SynthSeg only as comparator and fallback for large tissue volumes: 3.1 % traveling-subject variation on average, up to 15-20 %, amygdala and ventral DC 7-8 %, systematic hippocampal offset [8]; no independent evidence that it is more site-robust than FreeSurfer on 1 mm MPRAGE.

A benchmark on the pilot plus the 40 repeat pairs (task wd6, running) compares SynthSeg robust, SynthSeg fast, FastSurfer CNN, FreeSurfer aseg and FSL FAST/FIRST on ICC, SDC95, Dice against FreeSurfer, infarct robustness, failure rate and runtime; the decision follows the table.

9. Segmentation errors across time points (M0, M10, M60): detect and handle

Detect. Per time point: Euler number (per-site threshold), MRIQC, recalibrated Qoala-T [15-18]; a time point whose Euler number drops far below the participant's other time points is suspect even if the cohort rule passes. Within participant: fit a robust line per ROI and flag residuals above the local SDC95; flag non-monotonic jumps in structures that only shrink; flag sudden left-right asymmetry changes; check that ICV is constant within participant (drift = skull strip or registration error). Visual QC of all flagged sessions, a random 10 % of the rest stratified by site and visit, and the lesion-heaviest decile.

Handle, in this order. (1) Rerun with lesion-filled T1 and, where the FLAIR is good, -FLAIRpial [13]. (2) The longitudinal stream reduces time-point-specific errors because each time point starts from the template [3,7], but it cannot repair an error that is in the template: fix or exclude a bad time point BEFORE building the base. (3) Manual edits (brainmask, wm.mgz, control points, pial) only for flagged cases, one editor, documented, applied to the cross-sectional run and then base and long rebuilt; edits had large effects on subcortical volumes in the Maastricht Study [16]. (4) Exclude single time points, not participants; mixed models tolerate missing visits. (5) Report with and without flagged data, with a per-time-point QC covariate, and a sensitivity analysis because failures concentrate in the sickest [13]. Expect more than 10 % first-pass failures in this population (ONDRI unmodified: 11 % ribbon and 62 % tissue fails [13]).

11. Presenting it: storyline and expected questions

Suggested 10 slides: (1) question and cohort; (2) data: sites, visits, series, integrity check; (3) pipeline diagram with versions; (4) one QC page screenshot, explain RAW / INFARCT EXCLUDED and the counted groups; (5) measurement error table and what SDC95 means for one person; (6) trajectories: ventricles, thalamus, hippocampus, ipsilateral thalamus; (7) cortical thickness status; (8) QC gate and error handling across time points; (9) why FreeSurfer, the ordered improvement plan with references; (10) full-cohort plan and compute.

Questions you will get, with the answer in one or two sentences: - Why SynthSeg for volumes if FreeSurfer is the main tool? It is contrast-robust and 1-2 minutes per image, so it gives the complete volume table and a QC score for all 1652 images first; FreeSurfer surfaces are the primary tool for thickness and for the longitudinal stream; small structures are never mixed across tools [5,8]. - Why not fill WMH? For SynthSeg volumes, filling changed GM by at most 0.5 % in our 22 M0 sessions; for FreeSurfer surfaces the literature says fill, so the FreeSurfer runs will use filled T1 after the pilot [10-13]. - How do you know a change is real? It must exceed the SDC95 of that structure (2.5 % hippocampus, 4-5 % thalamus here) and survive the QC gate; cohort slopes come from mixed models, not from single differences. - Is 0 to 6 months useful? For atrophy no: at 2 years the ICC of change is 0.24 in healthy adults [7]; 6 months is a reliability estimate and a check on acute-phase effects. - What about seven scanners? Same vendor and sequence family; longComBat on the tables after QC, with site as random effect in a sensitivity analysis [21,23]. - How many will fail? Expect over 10 % first-pass failures; the gate, lesion filling and reruns are planned for that [13,16]. - Your follow-up volumes ignore the old infarct? Yes, today: the DWI mask is acute-only; the chronic mask (carried forward + MAPPING on T1) is being built, and SynthSeg already drops cavities from the totals, so the remaining bias is the gliotic rim counted as tissue. - Why these reliability numbers if the segmentation is "deep learning"? Deep learning changes the error pattern, not the need to measure it; our test-retest is an upper bound and the exact rerun is queued.

12. Glossary

ICV / eTIV: intracranial volume (SynthSeg "total intracranial"; FreeSurfer estimated total intracranial volume). SDC95: smallest detectable change at 95 % confidence for one person. ICC(2,1): intraclass correlation, two-way random, absolute agreement, single measure. CV: coefficient of variation = within-subject SD / mean. Euler number: 2 - 2 × (number of holes) of the initial cortical surface; -50 is typical, below the cohort cutoff is suspect. RAW / INFARCT EXCLUDED: volumes before / after removing infarct voxels. Base / long: FreeSurfer longitudinal template and time-point runs. Desikan-Killiany: 34-region cortical atlas per hemisphere (labels 1000-1035 left, 2000-2035 right).

Aussage

With FreeSurfer 8.2 as the main tool, the evidence-backed levers for volumes and cortical thickness in a stroke / small-vessel cohort with visits at 0, 6, 36 and 60 months are, in order of expected gain:

  1. Longitudinal stream instead of per-session runs. In 11 datasets (n = 3,611, FS 7.1) the cross-sectional stream was about 0.25 ICC lower for change than the long stream; ICC of change for 3 visits was 0.24 at 2 years, 0.54 at 4, 0.72 at 6 [7]. The 0 to 6-month contrast is therefore mostly noise; atrophy rates should come from 0/36/60 months. Baseline-only participants (121 of 586 here) are run as one-time-point bases and enter mixed models for intercept and covariate effects.
  2. Lesion handling before recon-all. Unfilled WM lesions bias GM up and WM down (+2.3 % / -3.6 % for 15 ml, cut to 0.1 % by filling) [10]; masking alone does not remove the bias, refilling does [11]; 72 % of MS lesion volume was labelled GM and unfilled cortex came out thinner [12]. In chronic stroke / SVD (ONDRI, n = 155) a lesion- and atrophy-aware FreeSurfer procedure raised acceptable ratings from 18 % to 76 % (ribbon) and cut tissue-segmentation failures from 62 % to 8 % [13]. Fill WM lesions (WMH + WM infarct) with FSL lesion_filling; cortical or cavitary infarcts via inpainting (FastSurfer-LIT, validated on tumours and cavities, not yet on infarcts [14]) or masking; ALWAYS exclude lesion-overlapping vertices and voxels from ROI statistics.
  3. FLAIR for the pial surface (-FLAIRpial). Plausible for WMH-rich brains, but no quantitative study was found: test it on 30-40 sessions against Euler number, edit need and the local SDC95 before using it cohort-wide.
  4. QC gate per session. Euler number is the best automated correlate of manual quality (AUC 0.98-0.99, n = 1,840) [15]; in the Maastricht Study Euler number and MRIQC were the best strategies and excluding global-morphology outliers made things worse [16]; Qoala-T (AUC 0.98) needs recalibration [17]. Head motion lowers GM volume and thickness by about 0.7 % per mm/min even after visual QC [20], the same order as yearly atrophy, so keep a motion proxy as covariate.
  5. Local test-retest. The 40 sessions with two T1 acquisitions in the same session give the cohort's own SDC95 per ROI; use it as the threshold for implausible within-subject jumps (section "errors" below) and to decide which small structures (amygdala, thalamus) are interpretable.
  6. Harmonisation on the tables. ComBat removed scanner effects in cortical thickness across 11 scanners [21]; longComBat (ADNI, n = 663) is more powerful for change and controls type I error better than scanner-as-covariate [23]. Apply after QC, protecting age, sex, group and lesion load.
  7. SynthSeg only as comparator / fallback for large tissue volumes: traveling-subject variation 3.1 % on average, up to 15-20 %, amygdala and ventral DC 7-8 %, hippocampi systematically larger than FastSurfer's [8]; no independent evidence of better site robustness than FreeSurfer on 1 mm MPRAGE. SynthSeg inside FreeSurfer 8.2 is CPU-only here (see linked finding).

Segmentation errors across time points (M0, M10, M60): detect and handle. Detect per time point with Euler number (per-site threshold), MRIQC, recalibrated Qoala-T; within participant flag residuals from a robust line above the local SDC95, non-monotonic jumps in structures that only shrink, sudden asymmetry changes, and TIV drift (skull-strip or registration error). Handle in this order: rerun with lesion-filled T1 (and -FLAIRpial where the FLAIR is good); manual edits only on flagged cases, one editor, documented, on the cross-sectional run BEFORE building the base so the template inherits the fix (edits had large effects on subcortical volumes in the Maastricht Study [16]); the long stream reduces time-point-specific errors but cannot repair an error in the template [3,7]; exclude single time points, not participants; mixed models with a per-time-point QC covariate and a sensitivity analysis, because failures concentrate in the sickest [13]. Expect a first-pass failure rate above 10 % in this population (ONDRI unmodified: 11 % ribbon, 62 % tissue fails [13]).

Aussage

mri_synthseg in FreeSurfer 8.2.0 uses the bundled fspython with TensorFlow 2.13.1 built WITHOUT GPU support (tf.config.list_physical_devices('GPU') returns [] on a machine with a working CUDA 12.4 torch). Measured on a 24-core workstation: --parc --robust --cpu --threads 6 takes about 85 s per 1 mm MPRAGE, plus about 20 s model load per call. Running batches of 40 images as a folder (--i <folder> --o <folder>) loads the model once per batch. Three batches in parallel (about 10 GB RAM each) give about 1652 sessions in 13-15 h on one workstation, with no GPU needed, so a local LLM can keep the GPU. FreeSurfer 8.2 recon-all -all measured 40-48 min per session with -openmp 4, 3 in parallel, peak RAM 17-28 GB per run (mri_synthseg / mri_synthmorph stages); the literature figure of 4-7 h per recon-all is for FreeSurfer 6/7.

Traegt

Compute plans for cohorts of 1000+ sessions on single workstations; the choice between SynthSeg-in-FreeSurfer and a standalone SynthSeg/FastSurfer with GPU; the decision not to stop a local LLM server for a SynthSeg batch.

Traegt nicht

Standalone SynthSeg (own TensorFlow with CUDA) and FastSurfer (PyTorch) -- both use the GPU; FreeSurfer versions other than 8.2.0.

Bruchindikator

A FreeSurfer release whose fspython lists a GPU, or a measured --robust time far from 85 s on comparable hardware.
